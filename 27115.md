# Onboarding

1. This repository is forked from FTC official Github repo at https://github.com/FIRST-Tech-Challenge/FtcRobotController 

2. In order to understand the project structure, read the two following documents inside the project carefully

````text
TeamCode/src/main/java/org/firstinspires/ftc/teamcode/readme.md
FtcRobotController/src/main/java/org/firstinspires/ftc/robotcontroller/external/samples/readme.md
````
3. The project contains two subprojects  
```text
FtcRobotController  - Sample FTC Controller code
TeamCode            - Our own code to develop and generate final APK file to deploy to Robot 
```
# Setup

JAVA 17 is recommended for Gradle JDK setting in Android Studio
> Settings > Build, Execution, Deployment > Build Tools > Gradle

# Build
Command line to generate APK file:
```text
./gradlew assembleRelease
```

The APK file location:
```text
TeamCode/build/outputs/apk/release/TeamCode-release.apk
```
